## How to Share

You can:

1. **Share the entire folder** - Zip the `shareable/` folder and email/transfer it
2. **Email the PDF** - Send `cycling_coaching_guide.pdf` for easy reading
3. **Share Zwift workouts** - Copy the `zwift_workouts/` folder for ready-to-use training sessions
4. **Print materials** - The PDF prints well for offline reference
5. **Use as discussion material** - Review the coaching guide together

**Recommended for non-technical users:**

- Share `cycling_coaching_guide.pdf` (easier to read than markdown)
- Include `zwift_workouts/` folder with installation instructions
- Optionally include `workout_plan.txt` for reference

## Privacy Note

All personal identifiable information has been removed or generalized. The workout structures and training principles are universal and can be applied by any cyclist looking to improve their endurance performance.
